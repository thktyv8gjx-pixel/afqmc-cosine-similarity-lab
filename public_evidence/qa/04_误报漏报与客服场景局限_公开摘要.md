# Internal-tune error profile and practical limits (public summary)

All figures below are from internal tune, where each model's threshold was selected. They are not independent validation results.

| Method | False positives | False negatives | F1 | False-positive rate | Predicted-positive share |
|---|---:|---:|---:|---:|---:|
| Count character 2-gram + cosine | 4,602 | 35 | 0.472888 | 0.968434 | 97.31% |
| TF-IDF character 2-gram + cosine | 3,871 | 258 | 0.473543 | 0.814604 | 83.41% |

Manual case review examined surface-overlap false positives and low-score positive paraphrases, including cases involving number, time, amount, negation, or entity changes. These observations are qualitative. No reliable automatic theme classifier or per-theme total was produced, so they must not be interpreted as estimates of how often each failure type occurs.

Character overlap is a weak proxy for meaning: a high score can arise from shared wording even when the requested entity, state, or amount differs; a low score can occur when equivalent requests use different wording. The full local case sheet contains row-level questions and is intentionally excluded from this public repository.
