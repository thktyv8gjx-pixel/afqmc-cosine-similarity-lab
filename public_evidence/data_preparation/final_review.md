## 使用方式及剩余限制

按仓库README安装专用依赖后：

```powershell
python scripts/check_afqmc_synthetic.py
python scripts/test_prepare_afqmc.py
python scripts/prepare_afqmc.py
```

前两条只运行合成验证。第三条是使用者主动选择的数据准备命令，完整模式会先检查环境、源码和既有Manifest，再取得或读取数据。`--archive-only`仍只需Python 3.11及以上标准库，不检查数值依赖或重建Manifest；`--offline`禁止下载。

本轮没有发现需要修改历史实验方法或结果的问题。原始数据、Manifest、逐行结果、私有日志和个人报告不进入本次公开文件清单。已有其他工作区修改保留。
