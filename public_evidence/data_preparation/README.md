## 异常处理与本轮发现

1. **沙盒临时目录权限**：首轮24项测试在setUp/cleanup阶段被系统拒绝，共48个错误，未进入功能断言。取得相应执行权限后24项通过；补齐Test ID测试后最终26项通过。权限失败没有被记成算法通过。
2. **新字段校验遗漏Test ID**：首次真实下载因新校验器未列出Test的整数id而返回2；临时文件清理，未接纳半成品。依据历史Stage1既有字段审计修正该校验器，并新增整数/重复ID测试，随后正式数据准备通过。没有使用模型分数或Dev性能决定修复。
3. **Git检出的换行差异**：旧64文件课程候选清单中5个非源码JSON的原始字节哈希与Git LF检出不同，规范化内容一致。历史清单及文件未重写。新无数据入口仅复制实际所需39文件，源码仍核对冻结原始字节哈希，v1/v2测试配置核对已登记的规范化摘要并原样复制。初次缩减时缺少v1测试配置导致49项中11错误，补齐依赖后49项全部通过。此处理只用于合成测试快照，不放宽正式Dev发布门禁或恢复规则。
4. **网络、坏版本和安全门禁**：合成测试覆盖断网、下载不完整、异常跳转、超限下载、归档SHA/成员SHA/CRC、路径穿越、字段/标签错误、Manifest错误、原文件保留及原子发布。错误返回2并提供官方URL、目标路径和手工校验步骤；不记录问句内容。

旧64文件清单仍是历史候选，不能据此宣称当前Git克隆能逐字节重建那个旧课程包。当前新增源码与说明以本次公开提交为准，最终课程ZIP尚未制作。

## 新用户现在可以做什么

1. 安装项目专用依赖，运行`python scripts/check_afqmc_synthetic.py`及`python scripts/test_prepare_afqmc.py`，完全不需要原始AFQMC。
2. 从官方入口自动取得固定归档，校验全部拆分并重建精确Manifest；网络失败时手工取得同一版本后离线校验。
3. 在前提齐备且另行选择执行的情况下运行真实Train内部实验；本轮未运行，不能把准备成功写成性能复现通过。

正式Dev的新模型重放仍需另行授权及历史发布门禁；逐行结果独立复算需要本地私有预测/执行记录，正式报告和最终课程ZIP也不由下载入口生成。下载与准备不修改这些边界。
