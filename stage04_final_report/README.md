# Stage 4B 正式报告工作版

本目录基于教师原始Word模板制作课程报告的可编辑工作版及对应PDF，等待本人审核。封面资料及正式命名仍待确认。Word/PDF、模板核验图、页面PNG和真实案例核验明细只在本地保存；Public仓库仅提交安全审计记录。

## 工作文件

本地Word和PDF均以“待填学号_待填姓名_实验报告1_基于余弦相似度的中文客服相似问句识别”为工作名，位于本目录根部。PDF由Microsoft Word直接导出，文件指纹绑定关系见报告数字核对记录；没有单独重建一份PDF正文。

正文沿用4A并完成三项主要修订：模型输入仅为文本；误报差异同时受表示权重与各自阈值影响，不作单因素因果归因；工程与版本细节压缩到附录。所有真实实验方法、指标与阈值保持不变。

图1拆为12柱和8柱两个子图，图3拆为两个各含正负面板的子图；共享原分箱、比例分母和纵轴。图2保留553/2425/152/1186原四格计数，图4纵轴从0起。结果宽表拆为8个可读子表，表格字号10.5pt。
